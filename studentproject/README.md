# Feature In Event Planner ✅
* ### ปฏิทิน (Calendar): 
  >จุดประสงค์: ช่วยให้ผู้ใช้สามารถดูกิจกรรมที่กำลังจะเกิดขึ้นในปฏิทินได้อย่างชัดเจน โดย ผู้ใช้สามารถเพิ่มเหตุการณ์ใหม่ลงในปฏิทินได้ รวมถึงตั้งเวลาและสถานที่เป็นอันดับความสำคัญ 
* ### การเพิ่มเหตุการณ์ (Add Event): 
  >จุดประสงค์: ช่วยให้ผู้ใช้สามารถสร้างและเพิ่มเหตุการณ์ต่างๆ ลงในปฏิทินได้อย่างสะดวก โดยผู้ใช้กรอกรายละเอียดเหตุการณ์เช่น ชื่อเหตุการณ์ วันที่ เวลา สถานที่ และรายละเอียดอื่นๆ เพื่อให้สามารถจัดการได้ง่ายขึ้น 
* ### ดูเหตุการณ์นั้น (View Event): 
  >จุดประสงค์: ช่วยให้ผู้ใช้สามารถดูเหตุการณ์สำคัญๆที่ผู้ใช้ได้ทำการสร้างไว้ได้ 
* ### การแก้ไขเหตุการณ์ (Edit Event): 
  >จุดประสงค์: ช่วยให้ผู้ใช้สามารถบันทึกหรือแก้ไขข้อมูลและระบุรายละเอียดอื่นๆเพิ่มเติมเกี่ยวกับกิจกรรมหรือเหตุการณ์นั้นๆที่ผู้ใช้เคยทำการสร้างไว้
* ### เหตุการณ์ประจำวัน (Today Event):
  >จุดประสงค์: ช่วยให้ผู้ใช้สามารถเห็นเหตุการณ์ประจำวันนั้นๆได้อย่างง่ายดายมากขึ้น โดยจะไฮไลท์เหตุการณ์ที่ผู้ใช้เคยเพิ่มไว้ในวันนั้นๆ ทำให้ผู้ใช้สามารถจัดการได้สะดวกขึ้น
* ### เข้าสู่ระบบ/สมัครสมาชิก (Login/Register):
  >จุดประสงค์: ช่วยให้ application สามารถรองรับ user หลาย ๆ user ได้

# Instruction Event Planner Application 📝
* ### สามารถดูกิจกรรมที่ต้องทำแต่ะละวันในปฏิทิน
* ### สามารถเพิ่มกิจกรรมที่ต้องการทำในวันนั้นโดยกดปุ่ม + ด้านล่างขวา เเละใส่ข้อมูลวันที่ เวลา สถานที่ เเละคำอธิบาย หลังจากนั้นกด Save เพื่อบันทึกกิจกรรม
* ### สามารถดูกิจกรรมที่เพิ่มเเล้วได้ โดยการกดไปที่ กิจกรรมนั้นๆ ซึ่งจะบอกรายละเอียด วันที่ เวลา สถานที่ เเละคำอธิบาย
* ### สามารถแก้ไขข้อมูลการทำกิจกรรมนั้นๆได้ โดยการกดที่ปุ่มดินสอในหน้าของการดูกิจกรรมเพื่อเเก้ไขข้อมูล
* ### สามารถลบกิจกรรมที่เคยสร้างไว้เเล้วไม่ต้องการได้ใน หน้าของการดูกิจกรรม โดยการกดปุ่มรูปถังขยะเพื่อลบข้อมูลกิจกรรมนั้นๆ
* ### สามารถดูกิจกรรมที่ต้องทำประจำวัน ที่ด้านบนสุดขอกหน้า (ด้านบนของปฏิทิน) โดยจะเเสดงทุกกิจกรรมที่ต้องทำภายในวั้นนั้นๆ
* ### สามารถเข้าสู่ระบบ หรือสมัครสมาชิกได้ และกิจกรรมของแต่ละ user ไม่ควรจะ interference กัน
